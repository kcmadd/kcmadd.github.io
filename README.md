# kcmadd.github.io

Personal website for Kalyan Maddineni. Plain HTML, CSS and JavaScript, no build step.

## Structure

```
index.html          page markup
css/style.css       all styles
js/main.js          nav highlighting, scroll reveal, card hover glow
js/simulation.js    interactive price-path chart in the hero
images/             logos and favicon
resume/             resume PDF
CNAME               custom domain for GitHub Pages
```

## Running locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```
